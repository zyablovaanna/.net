# Веб-приложение для рецептов с управлением пользователями и хранением данных через .NET
# Пользователи:

## Автор рецептов:
•	скачать приложение, открыть его в браузере

•	зарегистрироваться (авторизоваться)

•	создать рецепт

•	опубликовать рецепт

•	сохранить рецепт в черновик

•	смотреть свои черновики

•	смотреть статистику рецептов - кол-во добавленных в избранное, кол-во просмотров

•	просматривать подписчиков (профили)

•	удалить рецепт

•	изменить рецепт

•	обратиться в поддержку

•	просмотреть статусы рецептов (отклонен, опубликован)


### Читатель рецептов:

### Анонимный:

•	скачать приложение, открыть его в браузере

•	просмотреть ленту рецептов

•	поиск рецепта

•	фильтрация рецептов по категориям

•	открыть рецепт

•	включить голосовое сопровождение рецепта



### Авторизованный, зарегистрированный:

•	скачать приложение, открыть его в браузере

•	зарегистрироваться (авторизоваться)

•	просмотреть ленту рецептов

•	поиск рецепта

•	фильтрация рецептов по категориям

•	открыть рецепт

•	оценивать рецепты

•	комментировать

•	включить голосовое сопровождение рецепта

•	выбрать случайный рецепт

•	составить меню на неделю

•	ф-ия что в холодильнике (подбор рецепта по выбранным продуктам)

•	добавить рецепт в избранное

•	посмотреть избранное

•	подписаться, отписаться на автора

•	обратиться в поддержку


## Тех. поддержка:

•	скачать приложение, открыть его в браузере

•	зарегистрироваться (авторизоваться)

•	просмотреть список обращений

•	открыть обращения

•	закрыть обращения

•	ответить на обращение

•	обращаться к админу


## Модератор, редактор рецептов:

•	скачать приложение, открыть его в браузере

•	зарегистрироваться (авторизоваться)

•	просмотреть список рецептов

•	открыть рецепт

•	проверить на нарушения и соответствия правилам сайта

•	разрешить публикацию/отклонить публикацию рецепта

•	обратиться в поддержку


## Администратор:

•	скачать приложение, открыть его в браузере

•	зарегистрироваться (авторизоваться)

•	назначать модераторов и тех поддержку

•	добавлять новые категории рецептов

•	удалять рецепты, если на них много жалоб и модератор что-то пропустил

•	удалять пользователей


#### Рецепт - фото, кухня, тип блюда, время приготовления, сложность, острота, шаги рецепта (фото + текст), кнопочка добавить в избранное, рейтинг, отзывы, комментарии


#### Обращения - отправитель, текст, картинка, тип обращения, категория, статус,дата


#### Избранное - список рецептов
Возможность редактировать профиль - (добавить фото, изменить данные), удалить профиль
